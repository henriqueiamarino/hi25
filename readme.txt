== Description ==

HI25 is the 2025 edition of a yearly series of personal blog themes by Henrique Iamarino, a theme designer at Automattic. Launched in 2026, it frames your writing with bold cards, Manrope type and a choice of accent palettes, plus templates for book reviews and showcases and a full-screen menu overlay. A new edition arrives on WordPress.org every year. If you’re a creative person, use it to blog more, share your process and passions, and make sharing a regular part of your routine.


== Changelog ==

= 1.1.1 =
* Readme: license details and source URLs for the images shown in the screenshot.

= 1.1.0 =
* Renamed to HI25 (slug hi25).
* Removed the Section Title pattern.
* New patterns: Readings, Readings with Covers and Specials.
* The footer and the navigation overlay show the theme author’s halftone photograph from Courmayeur, a signature for the yearly series.
* Color palettes as style variations: orange (the default), yellow, pink, blue, golden, purple, green and teal.
* Each palette gives avatars, covers, post author images and featured images its own duotone. New Duo Purple, Duo Golden, Duo Green and Duo Teal duotones.
* The accent no longer changes on every visit, so the editor and the site always show the chosen palette.
* The Categories dropdown label is set through a WordPress filter instead of matching core text.
* On a site with no categories yet, the editor’s “No categories” message keeps the header’s compact size.

= 1.0.8 =
* One main landmark per page: the header and footer wrappers are no longer main elements.
* Search results: the header now renders above the content.
* Home: the hero image loads eagerly with high fetch priority. Add the is-hero class to any Post Featured Image block for the same effect.
* Single and Book Review: Previous and Next links within the category.
* Archive: the no-results message now fits archives.
* Navigation Overlay: refined spacing, a smaller close button and a narrower menu column.

= 1.0.7 =
* New Navigation Overlay template part: a full-screen menu with a short introduction and a portrait.
* New portrait-tilt utility class: a tilted image with a gentle wobble, switched off for reduced motion.

= 1.0.6 =
* Renamed from I’m H25 to H25 (slug h25).
* One post footer shared by Single, Book Review and Theme Showcase.
* Quote and Pullquote restyled as cards with a quote glyph.
* Book Review shows the post title and drops the date and the Share and Like row.
* One H1 per page: the Specials card title is an H2, the 404 heading an H1, and the author archive opens with a “Meet the Author” label.
* Home: new sections built from tag and category queries.
* Tables: headers aligned left and striped rows.

= 1.0.5 =
* One accent color per visit, picked at random from six and never the same twice in a row.
* Manrope is now the only typeface.

= 1.0.4 =
* Block-specific CSS moved from style.css into theme.json.

= 1.0.3 =
* Removed editor-only overrides for visually hidden text, now fixed in Gutenberg.

= 1.0.2 =
* Bug fixes and coding-standards cleanup.
* The Categories dropdown placeholder reads “Read by Category”.

= 1.0.0 =
* Initial release
